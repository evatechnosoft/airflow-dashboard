# /help-me

Bu proje icin hizli komut dizini.

- `/help-me`: tum kisa yollari ozetler
- `/help-git`: git akisi ve branch/push rutinleri
- `/help-hooks`: hook kurulumu ve kontroller
- `/help-agent`: skill/agent/subagent otomasyonu
- `/help-deploy`: local/server deploy komutlari

## Hemen Basla
- `pwsh -NoProfile -File scripts/help-router.ps1 /help-me`
- `pwsh -NoProfile -File scripts/help-router.ps1 /help-agent`
- `pwsh -NoProfile -File scripts/help-router.ps1 /help-hooks`
